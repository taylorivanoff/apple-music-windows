# Apple Music for Windows

Apple Music desktop app for Windows. Loads [https://music.apple.com](https://music.apple.com) in a native **Tauri / WebView2** shell.

## Development

Requires Rust (MSVC), WebView2, and Bun. Sibling crates:

- `Projects/tauri-tray-base`
- `Projects/tauri-icloud-base`

```bash
bun install
bun run icon
bun run dev
```
